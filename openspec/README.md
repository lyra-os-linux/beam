# Especificações de `beam`

Os requisitos deste repositório, no formato do
[OpenSpec](https://github.com/Fission-AI/OpenSpec):

- `specs/<capacidade>/spec.md`: o comportamento vigente.
- `changes/<id>/`: as mudanças propostas (`proposal.md`, `design.md`,
  `tasks.md` e o delta em `specs/`). Depois de entregues, são arquivadas em
  `changes/archive/` e os requisitos passam para `specs/`.

As convenções (português, RFC 2119 com **DEVE**, **NÃO DEVE**, **DEVERIA** e
**PODE**, requisitos EARS e cenários **WHEN**/**THEN**) estão em
[lyra-ecosystem/openspec](https://github.com/lyra-os-linux/lyra-ecosystem/tree/main/openspec).
Uma mudança que atravessa repositórios tem a proposta-mãe lá, e cada
repositório guarda aqui a parte dele.
